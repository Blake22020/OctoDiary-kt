# School-service API notes

This file documents endpoints currently used by OctoPlan. The endpoints are observed interfaces of external school services, not a stable or officially supported public API. They may require an authenticated user session, return region-dependent data, or change without notice. Do not use these notes to bypass access controls.

Host names and availability are maintained in the network interfaces and service configuration. A successful response for one user or region does not imply that an endpoint is available to every account. HTTP errors should be shown as unavailable data with enough context to diagnose the failing operation, while keeping tokens and student records out of logs and issue reports.

Personal planner tasks are stored locally by [`PlannerTaskStore`](app/src/main/java/org/bxkr/octodiary/screens/navsections/homeworks/PlannerScreen.kt) and do not use these school-service endpoints.
